# entities-godot-springbone-test

An engine test scene that loops a walking rig through the spring-bone simulator, with a checkbox that resets the simulation on each loop.

## What it is for

It shows whether spring bones settle or jump when an animation restarts. The rig carries a collision capsule for the bones to hit.

## Build and run

Open the project in a double-precision build of the engine's editor, version 4.4 or later, and run `node_3d.tscn`.
